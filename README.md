# Public Assets

Central repository for hosting public media assets, avatars, icons, and static files.

## URL Formats

Assets in this repository can be referenced on the public internet using either GitHub's raw CDN or third-party edge CDNs:

### 1. jsDelivr CDN (High Performance & Global Caching - Recommended)
```
https://cdn.jsdelivr.net/gh/magicprompt/assets@main/<path-to-file>
```

### 2. GitHub Raw
```
https://raw.githubusercontent.com/magicprompt/assets/main/<path-to-file>
```
